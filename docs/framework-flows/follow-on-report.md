# Follow-on links with no document behind them

The old `follow_on_frameworks` lists had 52 links. Document links now carry the handoffs.
24 links were already covered by a document. 20 got a new helpful document. These 8 did not.
Seven have no document passing between the two frameworks. One would fail the market check.
Each is dropped. Say so if you want one back.

- Finding the Crux → Proximate Objectives: no document passes between them; Finding the Crux names the hardest challenge, and Proximate Objectives picks small goals from the user's own list.
- Forever Promise → Value Metric: a document could pass (the promise a subscription makes), but Forever Promise is B2C and Value Metric is B2B, and the market check fails a B2C writer that feeds only a B2B framework.
- Forever Promise → StoryBrand Homepage: no document passes between them; the promise may show up on a homepage, but the homepage already takes the positioning statement and brand voice guide.
- Kernel of Good Strategy → The Weekly Check-In: no document passes between them; the kernel's coordinated actions are not the quarterly goals the check-in reads, and Proximate Objectives already writes those.
- Ten Steps Blueprint → 3B Behavioral Design: no document passes between them; the blueprint designs a training program, and 3B designs a product flow.
- Interface Inventory → Logic Check: no document passes between them; the inventory lists the components in an app, and Logic Check needs a design-principles file or a screen.
- AI Search Optimization Checklist → Why My Page Doesn't Rank: no document passes between them; the checklist covers the whole site, and it sends the user to the other framework only when one page is not indexed.
- FEW HICCUPPS Review → Four Question Threat Model: no document passes between them; the review lists oddities in a design, and the threat model starts from the design itself.
