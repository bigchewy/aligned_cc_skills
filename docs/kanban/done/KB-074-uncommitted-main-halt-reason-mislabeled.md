# KB-074: `uncommitted_main` halt reason is mislabeled — fix-instructions misdirect users

- **Type:** bug
- **Discovered during:** root-cause-analysis (autopilot halt during merge of main into worktree)
- **Location:** `docs/ralph_loops/lib/halt.sh:100-107` and `docs/ralph_loops/phases/worktree.sh:108-114`
- **Observed:** `worktree.sh` fires `write_halt uncommitted_main` whenever `git merge main` exits non-zero AND `MERGE_HEAD` is set after the failure. That trigger condition is exactly "merge conflict between commits on main and commits on the feature branch" — it has nothing to do with uncommitted state on main. (`git merge main` from a separate worktree merges the *committed* state at `refs/heads/main`; main's working tree being dirty or clean is irrelevant.) The halt reason name and the canonical fix-instructions in `halt.sh:100-107` tell the user "Main branch has uncommitted changes" and instruct "Commit or stash the changes on main, then re-run." A user following that advice would stash nothing meaningful, re-run, and hit the same halt. Confirmed in practice on 2026-05-15: main was clean (`git status` showed only untracked files), the halt fired anyway, and the real failure was conflicts in `.claude-plugin/marketplace.json`, `.claude-plugin/plugin.json`, and `frameworks/reverse-engineered-brand/examples.md`.
- **Expected:** Rename the reason to something accurate (e.g., `worktree_merge_conflict`) and rewrite fix-instructions to guide conflict resolution in the worktree: `git -C <worktree> status` to list conflicts, resolve, `git -C <worktree> add` + `git -C <worktree> commit`, delete `.autopilot-halt`, re-run. Touch points: `lib/halt.sh` (rename case + new heredoc), `phases/worktree.sh:16` (EXIT CODES comment) and `:111` (write_halt call), `skills/_shared/autopilot-halt-format.md:41` (taxonomy table), `e2e/tests/test_halt_protocol.py:20,84` (EXPECTED_REASONS + parametrize needle). The drift-detection test at `test_halt_protocol.py:104-156` is already in place and will fail-fast on inconsistency.
- **Why out of scope:** Discovered during an active autopilot run; analysis filed; implementation deferred to a focused branch so the rename + test update happen as one atomic change. Cross-confirmed independently by the code-simplifier (HIGH severity).
- **Severity:** HIGH
