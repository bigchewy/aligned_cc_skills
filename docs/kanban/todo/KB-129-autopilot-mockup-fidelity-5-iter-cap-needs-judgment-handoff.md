# KB-129: Autopilot mockup-fidelity phase exits with "remaining deviations" warning instead of halting for judgment

- **Type:** bug
- **Discovered during:** root-cause-analysis (autopilot verify-gate failure investigation, 2026-05-17)
- **Location:** `scripts/autopilot/phases/mockup.sh` — fidelity loop and post-loop branch
- **Observed:** The mockup fidelity phase ran 5 iterations on `feature/framework-runner-refactor`. Each iteration applied real fixes (commits `4c262d7`, `1a7e605`, `f468d8f`, `9cc71cd`, `2fe2059`). At cap, the phase printed `WARNING: Mockup fidelity not fully resolved after 5 iterations. Remaining deviations will be visible during review.` and exited `passed`. The autopilot then proceeded to the verify phase (which failed for an unrelated reason — see commit fixing SETTINGS-LINK gap on the same day). Net effect: a real signal that mechanical retries are not converging was downgraded to an informational warning the user might not see in the log noise.
- **Expected:** When the fidelity loop hits its iteration cap without converging, the phase should halt the pipeline (write `.autopilot-halt` with `reason: mockup_fidelity_unresolved`) so the user is explicitly asked to triage the remaining deviations. Mirrors how `finishing-a-development-branch/SKILL.md:255-260` (Step 1g) hands off to the user for root-cause diagnosis when mechanical fixes stop working. The corresponding "fix-mockup-deviations" step in the human-driven finishing skill is user-directed precisely because at iteration 5+ the remaining deviations are judgment calls (cosmetic vs structural vs logic), not retry targets.
- **Why out of scope:** Surfaced while investigating an unrelated verify-gate failure (pytest permission inheritance gap in worktree). Fixing the mockup phase's exit policy is a separate behavior change that needs its own design — should it halt always, or only when iteration count >= 3 AND the same files appear in consecutive diffs? Should the halt carry the deviation report to the user, or just a pointer to the iteration logs?
- **Severity:** MEDIUM — does not corrupt data or block other phases, but launders a "needs human judgment" signal into a passing status, which contradicts the autopilot's halt-loudly-on-unresolved-ambiguity discipline.
- **Created:** 2026-05-17
