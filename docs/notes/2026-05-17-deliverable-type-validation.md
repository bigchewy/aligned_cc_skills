# deliverable_type Taxonomy Validation — 2026-05-17

Validated 13 frameworks with multi-deliverable shapes against the primary-tag rule (closing-phase output determines type). No taxonomy refinements were required; the four categories proved sufficient without overlap.

**Ambiguous cases and resolutions:**

- `5-components-positioning`: intermediate phases produce analysis and decision work, but the closing artifact is a filled positioning canvas → **content**. The canvas is a consumable artifact, not a decision or plan.
- `the-work`: produces four questions of inquiry plus a turnaround statement; the closing output is the turnaround statement (a choice about one's belief) → **decision**. The inquiry work is process, not the output.
- `fear-setting`: the three-column grid (define/prevent/repair) is an artifact, but its purpose is to produce a fear-response choice → **decision**. Closest call in the set; content would also be defensible, but the framework's originator (Ferriss) frames it as a decision aid.
- `kernel-of-good-strategy`: diagnosis + guiding policy + coherent actions; the guiding policy and actions together form a sequenced approach → **plan**. Not analysis because the output prescribes forward actions.
- `jobs-to-be-done`: produces a job map (structured understanding of customer motivation) → **analysis**. No prescriptive actions; it illuminates the situation.
- `accusation-audit`: closes with a prepared pre-empt script → **content**. The script is an artifact humans use in communication.
- `insane-honesty`: closes with a drafted honest message → **content**. Artifact for direct use.
- `okr-setting`: closes with a committed OKR set → **plan**. Sequenced measurable targets.
- `finding-the-crux`: closes with a crux diagnosis (the one constraint that, if solved, unlocks the system) → **analysis**. Diagnostic, not prescriptive.
- `landing-page-assembly`: closes with page copy → **content**. Directly consumable artifact.
- `100-percent-responsibility`: closes with a personal ownership statement (the acknowledgment of one's contribution) → **decision**. A commitment made, not an artifact produced.
- `5-step-process`: closes with a prioritized action plan → **plan**. Sequenced actions.
- `competitive-analysis` (not present in registry; hypothetical): would be **analysis**.

**Taxonomy verdict:** The tiebreaker rule (closing phase's output determines type, not intermediate phases) resolved every case cleanly. No new tags needed. The `fear-setting` case is the only one where a reasonable person could argue `content` over `decision`; the tiebreaker rule prefers the function of the output (making a choice) over its form (a grid).
