Plugin Split: aligned-advisors + aligned-works

Mono-repo architecture splitting one plugin into two (post-critique revision)

Separates the advisor layer (personas + frameworks) from the creation workflow stack (17 skills, agents, hooks, CLI-optimized). Three of five advisor skills use CLI features, so full Desktop compatibility is a future goal, not a launch guarantee. Both plugins coexist in the same repo with symlinks for cross-references. Migration happens on a feature branch.

Marketplace Configurationindependent install

Each plugin gets its own marketplace.json with a path field that tells the marketplace to treat the subdirectory as the plugin root. Both plugins are installable independently from the same repo.

  • Source path offsets — "path": "aligned-advisors" and "path": "aligned-works" point the marketplace to the correct subdirectory
  • Independent versioning — both start at 1.0.0, then version independently
  • Snapshot caveat — symlinked content is snapshot at install time; updating advisors requires reinstalling works

{
  "source": {
    "source": "github",
    "repo": "bigchewy/aligned_cc_skills",

Symlink Resolution Mechanismconfirmed working

How symlinks bridge the two plugins at the filesystem level. During plugin cache copy, symlinks resolve to real paths, so skill files continue to reference advisors/ and frameworks/ as if they were local directories. Empirically confirmed 2026-04-08 — both in-place (--plugin-dir) and via marketplace cache copy.

  • Symlink creation happens in Phase 1 of migration
  • Path resolution is transparent to skill files — no code changes needed
  • Fallback plan if symlinks break at runtime: explicit Glob-based advisor plugin root resolution in ~12 skill and agent files

Testing Strategy6 validation tests

The migration is a structural change, not a code change — traditional unit tests do not apply. Validation is script-driven. Each test targets a specific assumption that could silently break after the split.

TestWhat it verifiesHow
Symlink resolution Advisor content reachable from works plugin Load works plugin, invoke skill that reads advisors/registry.md
Hook discovery Hooks load from aligned-works/hooks/ Load works plugin, trigger a hook, verify it fires
Prefix completeness No stale aligned: references remain grep -r 'aligned:' --include='*.md' across both plugin dirs, filter known exceptions
Skill count Each plugin.json lists correct skills Count entries in skills array, compare to directory listing
Independent loading Each plugin loads without the other Load each via --plugin-dir in isolation, verify skill list
Cross-plugin invocation Works skill can invoke advisor skill Load both plugins, invoke a works skill that dispatches an advisor skill
