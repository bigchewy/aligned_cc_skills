Aligned Claude Code Plugin — Architecture

Component map for the aligned plugin (v0.8.1)

This diagram maps all component categories in the Aligned Claude Code Skills Plugin: skills (29), agents (10), hooks (lifecycle automation), advisor personas (71), frameworks (134+), and the plugin configuration layer. It shows how they relate and how Claude Code activates each type at runtime.

System Overview

How Claude Code loads and activates the plugin at runtime.

Development Workflow Pipeline

Core skill chain from idea to deployed code. Skills call agents and each other via Task tool sub-agents.

Hook Lifecycle

Hooks fire automatically at Claude Code lifecycle events — no user action required.

Brainstorming Skill — Internal Flow

The most complex skill: dispatches sub-agents, runs Architect auto-consult, invokes agents for visual artifacts, and runs a critique round with advisor personas.

Advisor System

71 personas — real humans and synthetic roles — selected dynamically by skills during critique rounds.

Framework System

134 structured frameworks — each with a prompt.md defining phases — invoked interactively via use-framework.

Component Reference

Component Path Type Purpose
plugin.json .claude-plugin/plugin.json config Plugin entry point, version, metadata. Loaded by Claude Code on plugin install.
hooks.json hooks/hooks.json config Wires lifecycle events (PreToolUse, UserPromptSubmit, PostToolUse, PostToolUseFailure) to hook scripts.
CLAUDE.md CLAUDE.md config Project instructions injected into Claude's system prompt for every session.
brainstorming skills/brainstorming/SKILL.md skill Idea → design doc. Dispatches project-scan sub-agent, runs Q&A, critique round, visual artifact agents, commits all outputs.
writing-plans skills/writing-plans/SKILL.md skill Design doc → exhaustive implementation plan. Assumes zero codebase context in the reader.
executing-plans skills/executing-plans/SKILL.md skill Runs implementation plan in batches with verification checkpoints.
test-driven-development skills/test-driven-development/SKILL.md skill Enforces red/green TDD cycle. Test must fail before any implementation is written.
systematic-debugging skills/systematic-debugging/SKILL.md skill Root-cause-first debugging. Supports low and high severity modes with multi-agent investigation.
finishing-a-development-branch skills/finishing-a-development-branch/SKILL.md skill Deployment audit → test/build verify → merge options → archive plans.
use-advisor skills/use-advisor/SKILL.md skill Fuzzy-matches an advisor name and adopts that persona for the session. Lists available advisors if invoked bare.
use-framework skills/use-framework/SKILL.md skill Fuzzy-matches a framework and guides the user through its phases interactively.
eval-audit skills/eval-audit/SKILL.md skill Ensures LLM behavior surface changes have eval coverage. Triggered by [EVAL AUDIT] hook tag.
kickstart skills/kickstart/SKILL.md skill Scaffolds new projects with Aligned conventions: CLAUDE.md, docs, eval infrastructure, design principles.
code-reviewer agents/code-reviewer.md agent Dispatched by finishing-a-development-branch. Reviews code quality before merge.
architecture-diagram-generator agents/architecture-diagram-generator.md agent Produces HTML architecture diagrams and updates docs/architecture.md. Dispatched by brainstorming.
mockup-generator agents/mockup-generator.md agent Generates HTML UI mockups from design documents. Dispatched by brainstorming.
error-diagnosis agents/error-diagnosis.md agent Reads errors.jsonl populated by error-tracker hook. Classifies error patterns and identifies root causes.
code-simplifier agents/code-simplifier.md agent On-demand agent that identifies code complexity and simplification opportunities.
auto-approve-worktrees.js hooks/auto-approve-worktrees.js hook PreToolUse: automatically approves Edit/Write operations inside git worktrees.
check-eval-audit.sh hooks/check-eval-audit.sh hook UserPromptSubmit: injects [EVAL AUDIT] tag when the adaptive interval has elapsed.
error-tracker.js hooks/error-tracker.js hook PostToolUse (Bash) and PostToolUseFailure: logs all tool errors to errors.jsonl for diagnosis.
usage-tracker.js hooks/usage-tracker.js hook PostToolUse (Skill | Task): tracks skill and agent invocations for analytics.
advisors/registry.md advisors/registry.md content Canonical index of all 71 advisor personas with slugs, domains, and selection criteria.
advisors/prompts/ advisors/prompts/*.md content One file per advisor persona. "You are [Name]..." system prompt injected at critique time.
frameworks/ frameworks/*/prompt.md content 134 structured frameworks. Each prompt.md defines phases for interactive facilitation via use-framework.
