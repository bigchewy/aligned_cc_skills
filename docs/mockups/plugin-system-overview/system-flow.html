Four views of the system: installation, the core dev pipeline, hook and agent dispatch mechanics, and the advisor/framework layer. Each diagram is self-contained — open any tab to explore that slice of the system.

How a developer installs the plugin globally and how a new project gets bootstrapped. After plugin install, the /aligned:kickstart skill scaffolds the project structure and writes .claude/settings.json so the plugin auto-enables for all team members who clone the repo.

The core development pipeline from idea to merged code. Brainstorming feeds into plan writing, which feeds into execution in an isolated git worktree, then finishing (tests, build, merge, archive). The pipeline can run interactively or autonomously via a Ralph loop background process.

How hooks fire and how agents are dispatched. Hooks run on Claude Code lifecycle events (PreToolUse, PostToolUse, UserPromptSubmit). Agents are dispatched as sub-agents via the Task tool — they run in isolated threads and report back to the main conversation. The [TAG] injection pattern lets hooks signal Claude without breaking the conversation flow.

How the advisor and framework layers work. Advisors are persona prompts (62 total) that Claude adopts for the conversation. Frameworks are structured multi-phase processes within an advisor's domain. Both are browsable and invocable via dedicated skills. The brainstorming skill also draws on advisors automatically as critics during design review.
