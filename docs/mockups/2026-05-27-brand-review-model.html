What this redesign does

Replace the drifted v0.4.1 review output (a 4-tab CEO-vocabulary display_groups nav, a generic 2073-line locked template, ~151 granular open questions, fed by two extra sub-agents) with the older Marley model: 8 folder/area tabs, a self-themed HTML rendered in the prospect's own decoded brand, per-section grade + working/attention grid + a short decision-shaped question list, and ~5–15 curated owner-authority questions.

Success criteria

  • 1Self-themed review.html matching Marley's structure: logo/wordmark header, sticky 8-tab nav with N / 5 grade chips, per-section eyebrow + grade badge + summary + decision callout + working/attention grid + short OQ list.
  • 2Renders in the prospect's own decoded brand (@font-face, :root palette, logo) and degrades gracefully on a public-web-only build.
  • 3Exactly one canonical data file (review-data.json) + inline snapshot in review.html. No 150-item log. ~5–15 curated questions.
  • 4Sub-agent ETL, context-bloat guard, confidence tags, slot validation, and the PHASE 2.4 gate all preserved.
  • 5Eval coverage exists (currently zero): a scenario + trigger-map entry.

  • top: org, generated_at, brand_folder
  • source_counts: total_sources, usable_sources, canonical_markdown_files, review_sections, open_questions

  • theme: palette{17 hex vars}, fonts{heading,body}, logo{src|null, wordmark_text}
  • sections[]: id, label, grade(1-5), confidence(freeform str), status(eyebrow), summary, provided[], needed[], files[]; overview adds readout + recent_update(null first build)

Self-theming, per-asset graceful degradation

The design pass emits a theme manifest; the renderer wires each field independently. Palette always emits from decoded hex (works from public-web CSS); fonts and logo degrade per-asset. The review works offline.

Renderer contract

  • Render the 8 section panels server-side as static HTML (the Marley split); inline REVIEW_DATA only powers the paste-back JS.
  • Keep sanitize-before-serialize, JSON.stringify discipline, 6-check verify-before-open, abort-before-open.
  • Add asserts: null logo ⇒ a .wordmark span must exist; any emitted @font-face src must be relative (no http) — offline-safety.
  • Token set shrinks to {REVIEW_DATA_JSON}, {ORG_NAME} + theme-driven CSS emission; catch-all token regex stays as failsafe.

TDD strategy

Fixtures (rebuild)

  • test-fixtures/render/* → review-data.json-shaped: tiny / realistic / stress (valid); invalids — grade out of 1–5, missing theme.palette, OQ count > 15, null-logo→wordmark, remote-font-src→reject.
  • test-fixtures/oq-schema/* → thin curated shape + rich internal emission shape; drop display_groups/input_asks fixtures.
  • Keep auto-mode-inputs/, competitor-identity/ (PHASE 2 synthesis) — verify, don't assume.

Logic + eval

  • Curation: owner-authority selects decision-shaped P0/P1; backfill fills to floor; cap truncates by rank. Error paths: empty queue, all-P2 queue.
  • Renderer behavior + error-path tests (malformed theme, over-cap OQs, degradation).
  • ADD e2e/scenarios/use-framework/reverse-engineered-brand.yaml + a trigger-map.yaml entry — currently zero coverage; eval-audit flags surface-without-scenario.
