Framework Discovery: Before vs. After

Brainstorming session: advisor-framework-consolidation

Side-by-side swim-lane comparison of how use-framework discovers framework prompts. The BEFORE flow reads a .repos manifest, globs per-repo subdirectories, and falls back to ~/.claude/. The AFTER flow is a single flat glob of frameworks/*/prompt.md.

BEFORE: Manifest + Per-Repo Globs + Fallback

graph LR
    START([use-framework invoked]) --> STEP1A

    subgraph Tier1["Tier 1 — .repos manifest"]
        STEP1A["Read frameworks/.repos\nparse repo list"] --> GLOB_VA["Glob: frameworks/\nva-web-app/*/prompt.md\n~130 frameworks"]
        STEP1A --> GLOB_EPCH["Glob: frameworks/\nepch-projects/*/prompt.md"]
        GLOB_EPCH --> BUG["BUG: epch-projects\ndoesn't exist!\nActual dir is epch/"]
    end

    subgraph Tier2["Tier 2 — ~/.claude/ fallback"]
        STEP1C["Read ~/.claude/frameworks/\nprompts/ directory"] --> SYM_VA["Follow symlink:\nva-web-app/"]
        STEP1C --> SYM_EPCH["Follow symlink:\nepch-projects/"]
    end

    GLOB_VA --> MERGE
    BUG -->|"0 results\nsilent failure"| MERGE
    SYM_VA --> MERGE
    SYM_EPCH --> MERGE
    MERGE["Merge results\nacross tiers"] --> MISSING{Missing\nframeworks?}
    MISSING -->|"Yes — 2 EPCH\nframeworks lost"| LIST[/"List frameworks\ngrouped by repo"/]
    MISSING -->|No| LIST
