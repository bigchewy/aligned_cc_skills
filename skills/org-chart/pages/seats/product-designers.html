Design the screens, keep the design system consistent, and make the product easy to use.

Jobs

  1. Write the design rules every screen follows

    Design Principles · Steve Jobs

    Generating a design-principles document with implementation-ready tokens for colors, typography, and theme

    /aligned:use-framework design-principles
    Other ways to do this
    • Logic Check · Adham Dannaway

      Reading a design principles file or an existing screen, naming the rule behind every visual value, and listing every value picked by feel with the rule that fixes it

      /aligned:use-framework logic-check

  2. Turn a rough flow into real screens

    Breadboard to Pages · Brad Frost

    Turning a breadboard of places and actions into exact static screens built only from the project's design system, testing each one with real content and the cases that break it, at phone and desktop widths, and walking the screens against the story map

    /aligned:use-framework breadboard-to-pages

  3. List every pattern the app already uses

    Interface Inventory · Brad Frost

    Collecting every distinct pattern in an app that already exists, category by category, naming each one, and deciding what becomes a shared component, what is a recipe, and what stays a snowflake, so the app is rebuilt from one system instead of many one-offs

    /aligned:use-framework interface-inventory

  4. Find the steps where users stall or quit

    the Cognitive Friction Audit · Shirin Oreizy

    A systematic process for identifying and eliminating decision-making barriers in user journeys. Every friction point costs conversions

    /aligned:use-framework cognitive-friction-audit
    Other ways to do this
    • the Homer vs Spock Framework · Shirin Oreizy

      A behavioral science approach to understanding how people actually make decisions. People decide with Homer (emotional brain) first, then justify with Spock (rational brain). Marketing to Spock first fails; marketing to Homer first then giving Spock justification converts

      /aligned:use-framework homer-vs-spock
