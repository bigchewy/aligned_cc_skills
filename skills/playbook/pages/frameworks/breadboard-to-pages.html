Breadboard to Pages

It · ProductBrad Frost

Turning a breadboard of places and actions into exact static screens built only from the project's design system, testing each one with real content and the cases that break it, at phone and desktop widths, and walking the screens against the story map.

/aligned:use-framework breadboard-to-pages

Must have

  • a breadboard of the slice to build: each place, what the user can do there, and where each action leadsfrom User Story Map
  • the project's design-principles.md, so every screen uses the project's tokensfrom Design Principles

Helps to have

  • the story map the breadboard came from (docs/story-maps/{slug}.md), so the screens can be walked against itfrom User Story Map
  • real content: actual names, emails, labels, and the longest values the app allowsfrom outside
